# Elevator Subsystem

## Περιγραφή

Ο φάκελος αυτός περιέχει το **Elevator Control System** του έργου Smart Elevators.

Το υποσύστημα του ανελκυστήρα είναι υπεύθυνο για την αναπαράσταση της κατάστασης και της διαμόρφωσης ενός ανελκυστήρα, καθώς και για την παροχή ενός REST interface μέσω του οποίου μπορεί να επικοινωνεί με τα υπόλοιπα υποσυστήματα του έργου.

## Περιεχόμενα

Το υποσύστημα περιλαμβάνει τα ακόλουθα αρχεία Java:

- `ElevatorState.java` — Ορίζει τις πιθανές καταστάσεις κίνησης του ανελκυστήρα.
- `DoorState.java` — Ορίζει τις πιθανές καταστάσεις των θυρών.
- `Direction.java` — Ορίζει τις πιθανές κατευθύνσεις κίνησης.
- `ElevatorStatusDto.java` — Αναπαριστά την τρέχουσα κατάσταση ενός ανελκυστήρα.
- `DispatchInstructionDto.java` — Αναπαριστά μία εντολή αποστολής του ανελκυστήρα σε συγκεκριμένο όροφο.
- `ElevatorConfigDto.java` — Αναπαριστά τις παραμέτρους λειτουργίας του ανελκυστήρα.
- `ElevatorApiController.java` — Παρέχει το REST interface του υποσυστήματος.

## Καταστάσεις ανελκυστήρα

Οι πιθανές καταστάσεις κίνησης του ανελκυστήρα είναι:

- `IDLE`
- `MOVING_UP`
- `MOVING_DOWN`
- `STOPPED`

Οι πιθανές καταστάσεις των θυρών είναι:

- `OPEN`
- `CLOSED`
- `OPENING`
- `CLOSING`

Οι πιθανές κατευθύνσεις κίνησης είναι:

- `UP`
- `DOWN`
- `NONE`

## REST Interface

Το υποσύστημα παρέχει τα ακόλουθα REST endpoints.

### Dispatch Elevator

**Method:**

`POST /api/v1/elevator/{id}/dispatch`

Το endpoint χρησιμοποιείται για την αποστολή εντολής σε έναν συγκεκριμένο ανελκυστήρα.

**Request body:**

```json
{
  "destinationFloor": 120,
  "direction": "UP"
}
```

### Get Elevator Status

**Method:**

`GET /api/v1/elevator/{id}/status`

Το endpoint χρησιμοποιείται για την ανάκτηση της τρέχουσας κατάστασης ενός συγκεκριμένου ανελκυστήρα.

**Response:**

```json
{
  "elevatorId": "B",
  "currentFloor": 37,
  "state": "MOVING_UP",
  "doorState": "CLOSED",
  "targetFloors": [50, 100, 120]
}
```

### Update Elevator Configuration

**Method:**

`PUT /api/v1/elevator/{id}/config`

Το endpoint χρησιμοποιείται για την αποστολή παραμέτρων διαμόρφωσης σε έναν συγκεκριμένο ανελκυστήρα.

**Request body:**

```json
{
  "maxSpeed": 2.5,
  "doorOpenTime": 3,
  "minFloor": 1,
  "maxFloor": 150
}
```

## Τρέχουσα κατάσταση υλοποίησης

Η τρέχουσα υλοποίηση περιλαμβάνει τις βασικές δομές δεδομένων και τον ορισμό του REST interface του υποσυστήματος του ανελκυστήρα.

Η πραγματική λογική ελέγχου του ανελκυστήρα, η προσομοίωση της κίνησης, η λήψη του `elevatorId` από τη γραμμή εντολών και η σύνδεση των REST endpoints με την εσωτερική κατάσταση του ανελκυστήρα θα υλοποιηθούν σε επόμενο στάδιο.

## Συνεργασία με τα υπόλοιπα υποσυστήματα

Το REST interface έχει σχεδιαστεί για την επικοινωνία του Elevator Control System με τα υπόλοιπα υποσυστήματα του έργου.

Οι τελικές προδιαγραφές του REST interface πρέπει να συμφωνηθούν από την ομάδα, ώστε όλα τα υποσυστήματα να χρησιμοποιούν κοινά endpoints, δεδομένα και μορφές επικοινωνίας.
